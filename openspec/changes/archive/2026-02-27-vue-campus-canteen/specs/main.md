# 规格：校园食堂系统

## 学生点餐流程
### 菜单浏览
- **给定** 学生在首页
- **当** 他们选择一个食堂或窗口时
- **那么** 展示带图片、名称、价格、销量的菜品列表。
- **并且** 允许按类别（荤、素）或口味筛选。

### 购物车与结算
- **给定** 购物车中有商品
- **当** 学生进行结算时
- **那么** 允许选择“取餐时间”（立即 vs 预约）。
- **并且** 允许添加“口味备注”。
- **并且** 验证用户余额 >= 总价。
- **当** 确认后，扣除余额并创建订单。

### 订单追踪
- **给定** 一个活跃订单
- **当** 状态改变时（例如变为“待取餐”）
- **那么** 在“订单中心”更新状态。
- **并且** 发送实时通知（模拟/WebSocket）。

## 商家管理
### 仪表盘
- **给定** 一个已登录的商家
- **那么** 显示今日统计：订单数、总收入、Top 3 菜品。

### 订单处理
- **给定** 一个新进入的订单
- **那么** 播放声音/显示弹窗。
- **当** 商家点击“接单” -> 状态变为“制作中”。
- **当** 商家点击“出餐” -> 状态变为“待取餐” -> 通知学生。

### 菜品管理
- **给定** 菜品管理页面
- **那么** 允许添加/编辑/删除菜品。
- **并且** 允许切换“上架”/“下架”。
- **并且** 允许设置“每日特价”（降价）。

## 系统管理
### 用户管理
- **给定** 管理员用户列表
- **那么** 允许封禁/批准账户。

### 监控
- **给定** 监控仪表盘
- **那么** 显示所有系统订单的实时流。
