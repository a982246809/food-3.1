# 提案：校园食堂点餐系统

## 目标
构建一个简化的校园食堂点餐系统，专注于最核心的点餐和订单管理流程，降低开发复杂度，快速落地。

## 问题
- **效率低下**：传统排队浪费时间。
- **信息不对称**：学生不知道今天有什么菜。
- **管理不便**：商家手动记账繁琐。

## 解决方案
使用 Vue 3（前端）和 NestJS（后端）与 MySQL + Prisma 构建的全栈 Web 应用程序。

### 核心模块
1.  **学生端**：
    - 菜单浏览（清晰展示菜品、价格）。
    - 购物车与下单（支持堂食/打包）。
    - 订单中心（查看订单状态）。
    - 个人中心（简单的个人信息）。

2.  **商家端**：
    - 订单管理（查看新订单、接单）。
    - 菜品管理（简单的上架/下架、修改价格）。

3.  **管理后台**：
    - 基础的用户与商户管理。

## 削减的功能（简化开发）
- **无实时推送**：订单状态通过手动刷新或轮询查看，不使用 WebSocket。
- **无复杂模拟**：去除模拟小票打印等非核心视觉特效。
- **简化统计**：仅保留最基础的订单列表，不做复杂的 ECharts 图表。

## 风险
1.  **状态同步延迟**：用户需要手动刷新页面查看订单最新状态。
