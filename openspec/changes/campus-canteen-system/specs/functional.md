# 规格：校园食堂点餐系统（简化版）

## 学生体验

### 场景：学生下单
**Given** 我选择了菜品
**When** 我点击下单
**Then** 订单创建成功，状态为“待接单”

### 场景：查看订单状态
**Given** 我已下单
**When** 我刷新订单列表页面
**Then** 我可以看到订单的最新状态（如“制作中”或“已完成”）

## 商家操作

### 场景：商家处理订单
**Given** 有新订单
**When** 我刷新管理页面
**Then** 我看到新订单
**And** 我点击“接单”开始制作
**And** 制作完成后点击“完成”

### 场景：简单的菜品管理
**Given** 某菜品售罄
**When** 我将库存修改为 0 或下架
**Then** 学生端不再显示该菜品或显示已售罄

## 管理员
- 简单的账号增删改查。
