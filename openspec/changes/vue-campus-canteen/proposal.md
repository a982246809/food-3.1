# 提案：基于 Vue 的校园食堂点餐系统

## 为什么 (Why)
此变更旨在实现一个全面的校园食堂点餐系统，以现代化用餐体验，减少学生排队时间，并为食堂商家提供数据驱动的管理工具。

## 变更内容 (What Changes)
*   **学生端 (Student Client)**:
    *   首页/菜单浏览：支持按食堂、窗口、类型（荤/素）筛选，展示图片、价格和销量数据。
    *   购物车与结算：支持添加口味备注和选择取餐时间（立即/预约）。
    *   订单中心：跟踪状态（制作中、待取餐、已完成），查看历史记录及再来一单。
    *   个人中心：管理个人资料、余额/充值记录和常用地址。
*   **食堂管理端 (Canteen Management Portal)**:
    *   商家登录与看板：显示今日关键指标（订单数、销售额、热门菜品）。
    *   实时订单管理：模拟小票打印，接单/出餐状态更新，退款处理。
    *   菜品管理：增删改查操作，每日特价设置，库存控制。
    *   数据可视化：使用 ECharts 展示日/周销售图表和菜品人气排行。
*   **系统管理后台 (System Admin Panel)**:
    *   用户管理（学生/商家审核）。
    *   食堂/窗口结构配置。
    *   系统监控（订单流、投诉、公告）。
*   **创新功能**:
    *   智能推荐（“猜你喜欢”）：基于历史/趋势推荐。
    *   订单社交分享。
*   **技术栈**:
    *   前端：Vue 3 (Composition API), Pinia, Axios, Vant, ECharts.
    *   后端：NestJS, JWT,prisma.
    *   数据库：MySQL.
